# 1.4.0：快取、切頁與即時名單

- 公開站內切頁改用現有 React 導覽，保留網址、返回、錨點與另開分頁；進出管理後台仍完整載入。
- 會員姓名／註記／級數篩選與筆畫排序由瀏覽器處理，打字不再反覆請求；首次只載入一份完整名單，列印前重讀。
- 同時發生的公開 GET 共用在途請求，不保存 API 回應快取；成功報名後強制讀新名單，慢回應不覆蓋新結果。
- 個人賽與雙打名單、公開場次在可見頁面約每五秒同步；切回視窗立即核對，背景暫停，也保留手動更新。網路延遲仍會影響實際讀回時間。
- 寫入或結果未確定時保留原內容、request ID 及重試入口，背景更新不觸發重送；資格、名額、正取與候補仍由球館伺服器核對。
- JS、CSS 與說明示範圖改用內容 hash URL，可供瀏覽器長期快取；HTML、API、真實公告媒體、登入與錯誤回應維持 `no-store`。不在瀏覽器持久存放名單。

Cloudflare Worker 延續原本轉送責任，只放行來源已允許的編譯資產快取；不改 VPC binding、Tunnel、目的地、Turnstile 或其他 momonong.me 功能。Worker 先更新仍相容 1.3；球館升級 1.4 後才會開始送出新版快取標頭。

## 相容性與更新

版本提高至 1.4.0，依賴不變，資料表仍為 `0015_deployment_diagnostics`，沒有 migration。
從已完成 1.3 的球館更新，必須保留原 1.2 部署及 1.3 更新收據鏈。新版工具先核對身份、停寫、成組備份，
切換後比對所有資料表、schema 與媒體摘要（含原管理員及 session），一致才接通原 Tunnel。
不初始化、匯入、還原、重建管理員、刪資料卷或重開機；原帳號資料保留。

請使用 Release 附件 `update-club-v1.4.0.ps1` 的固定來源 SHA、更新器 SHA256 及 Docker digest；
不使用 `latest` 決定球館版本。未知／部分操作保留原收據與 ID，停止時回傳階段及代碼，不能直接重跑或重貼首次安裝碼。
細節見[球館更新指南](club-vpc-upgrade-1.4.0.md)與[效能設計](performance-1.4.0.md)。

## 驗證範圍

使用隔離合成資料核對前後端、桌機／手機及根路徑／子路徑。新增案例包含：Document／GET 計數、資產二次載入、
正候補／雙打跨瀏覽器同步、背景暫停、過期 GET 晚到、寫入結果未確定時保留恢復入口，以及更新失敗仍停止可確認的 writer。
後端完整檢查 682 項通過，之後補強的更新器另以最終 56 項驗證；JS／Worker 共 13 項、適用瀏覽器案例 71 項通過。前端型別、建置、離線鎖檔及 npm audit 通過（0 弱點）。隔離舊 1.3→新版映像在根路徑與子路徑均核對資料不變、原帳號登入、11 張說明圖、公開名單、備份及重啟。舊 self-registration fixture 的桌面／根路徑限制由 base-path 與 registration-linkage 案例補足手機／前綴連動；分批執行保留正式登入限流。

固定映像識別列於 Release；球館原生 Windows 更新、原帳密登入與現場速度感受，仍待使用者執行後確認。
