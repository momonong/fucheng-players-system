# 1.4.1 備份保留最近兩組

例行週備份預設保留最近兩組通過驗證的完整副本。每週一台北時間 04:00 的新備份成功後，才清理超額舊組。現有數量會在下一次成功的週備份後縮減。備份的資料庫、媒體封存及描述檔一起輪替，缺檔、雜湊錯誤及無法驗證的檔案會保留。

球館更新器支援由 1.3.0 或 1.4.0 升級。它核對既有部署與升級收據，停寫、成組備份並比對全部資料表與媒體摘要，通過公開健康檢查後才清理多餘的升級前備份。最近兩組已驗證副本保留，所有升級收據、原 Compose 副本與操作紀錄繼續供後續核對。

更新器會將球館原有的週備份保留設定從八組改為兩組。遇到未完成或結果不明的操作時停止，保留原 ID 與現場資料。清理失敗會提示警告。

管理員、session、會員、報名及媒體逐表核對保留。資料表版本為 `0015_deployment_diagnostics`，相依套件沿用 1.4.0。

## 球館更新

從 Release 下載 `update-club-v1.4.1.ps1`，將整段貼到球館 PowerShell。指令自動下載固定 commit 的更新器、核對 SHA256，再使用固定 Docker digest 更新。先儲存後台的編輯，更新期間網站會短暫無法使用。

看到 `COMPLETE：1.4.1 更新完成` 後，重新整理網站並用原帳密登入。若顯示停止，保留原輸出中的階段與代碼，交由維護者核對操作收據。

部署前檢查點、獨立手動備份、還原前備份及匯出檔由管理者保管。[球館更新指南](club-vpc-upgrade-1.4.1.md)與[輪替規則](deployment.md#球館備份輪替)列出詳細範圍。

## 驗證

完整後端 690 項合成測試通過，涵蓋新備份缺檔、舊備份雜湊不符、升級失敗、收據鏈、原管理員資料及重跑核對。審查補強後的備份與更新器另以最終案例核對，包含中斷後補做輪替與異常日期。隔離映像已驗證 1.3／1.4 來源、根路徑／子路徑四種組合，涵蓋全表摘要、原帳號登入、公開名單、11 張說明圖、成組備份、兩組輪替及重啟。固定映像識別列於 Release。球館 Windows 實際更新、原帳密登入與人工接受由使用者執行後確認。
