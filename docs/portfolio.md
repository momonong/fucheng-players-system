# 府城球館會員管理系統

## 專案概覽

府城球館用這套網站發布公告與比賽、提供會員級數查詢與線上報名，並讓管理員安排名單、處理候補與保留歷史版本。公開頁供球友查看資訊和報名，後台集中管理場次、會員與公告。見 [專案說明](../README.md)。

## 使用流程

球友選擇比賽、依姓名與辨識註記核對會員，完成驗證後送出。雙打可一人先報名等待搭檔，也可兩人一起送出，之後由管理員確認正取或候補。個人賽管理員可調整本場級數與表格位置、保存安排版本，並列印或匯出 Excel。見 [雙打報名與管理](doubles-registration.md)與[當次比賽級數與完整安排](../README.md#當次比賽級數與完整安排)。

## 系統架構

React 前端與 FastAPI 後端由同一個 Docker 映像交付，SQLite 資料和媒體由獨立資料卷保存。報名服務用資料庫交易一起更新名單和稽核紀錄，並以原請求 ID 辨識重複提交。安排表把長期會員級數、報名時的級數快照與本場調級分開保存，因此日後仍能解讀歷史名單。見 [部署說明](deployment.md)與[報名交易實作](../src/fucheng/registrations.py)。

## 實作與貢獻

專案將球館報名、表格安排、歷史版本和輸出串成一套操作流程。1.4.0 讓會員搜尋在瀏覽器完成，名單只在頁面可見時定期更新。1.4.1 更新器會逐項核對既有部署與資料、停寫並成組備份，待新版健康檢查通過才輪替超額備份。見 [1.4.0 效能改動](release-1.4.0.md)與[1.4.1 備份輪替](release-1.4.1.md)。

## 成果與限制

1.4.1 的發布紀錄列出 690 項合成後端測試，以及由 1.3.0、1.4.0 升級時對根路徑與子路徑的隔離驗證。球館端由現場使用者回報完成更新，資料、媒體與原管理員帳號核對一致。紀錄涵蓋該次版本與升級範圍，實體印表機和其他現場環境仍須個別驗證。見 [1.4.1 驗證](release-1.4.1.md#驗證)與[球館更新指南](club-vpc-upgrade-1.4.1.md)。
