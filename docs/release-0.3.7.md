# 0.3.7：會員分級表與頁面版面整理

## 使用者可見調整

- 導覽、頁面、瀏覽器分頁及列印標題統一為「會員分級表」；會員編輯顯示「會員級數」，報名快照篩選顯示「報名時級數」。文件同步修正，資料欄位與級數語意不變。
- 素食名單從最多 640px 縮為 420px，姓名／辨識註記、級數、多層欄名與隊名緊湊排列，長內容自動換行。24px 名單圖示放入素食按鈕右側，保留獨立 44px 觸控範圍；開名單不切換高亮，工具列按鈕同高。
- 公開首頁、會員分級表與報名頁移除重複綠色標題區及管理員入口，由白色網站導覽提供位置提示。保留可及性頁面標題與管理後台入口。
- 管理頁保留綠色導覽；受保護的會員分級表也使用共用管理導覽。管理功能與帳號區採一致間距，備份狀態與管理員名稱維持下一行靠右。
- 頁首、主內容及比賽控制區共用響應式左右留白；一般頁面保留閱讀寬度上限，排表保留較大工作寬度。手機仍可整張選手方塊拖曳、雙點資訊及獨立選單。

## 相容性與資料

Python／npm 同步 0.3.7。後端功能、依賴及 schema `0010_deployment_report` 不變，無新增 migration。runtime `FUCHENG_BASE_PATH` 仍以同一映像支援根路徑與 `/fucheng/`；公開 origin、完整代理 URI、Cookie Path 及持久資料操作契約沿用原規則。

## 驗證

沿用本輪已通過的 6 項桌面／手機流程測試（會員編輯、篩選及列印、公告發布／下架、公開導覽與素食操作），以及 30 組 360–3840px 合成頁面版面檢查；最終版核對左右對齊、無頁面橫向溢出及桌面管理按鈕間距。多層欄名、合併隊名及唯讀歷史名單另有既有桌面／手機通過證據。Chromium 模擬不等於 Android／iPhone 真機驗收。

發布前另完成後端完整測試 **211 passed**（2 個既有棄用警告）、uv locked sync、TypeScript／production build、npm high audit（0 vulnerabilities）及 `/fucheng/` 桌面／手機 **4 passed** 路徑回歸。發布前端與上述版面檢查成品逐檔完全相同。

發布檢查結果記錄於發布 PR／GitHub Release；本機證據位於受忽略的 `data/release-0.3.7/`。套件依 allowlist staging 與 source manifest 建置，不包含資料庫、帳密、備份或舊前端成品。
