# 1.3.0：站內使用說明與公開報名名單

本版將使用者已確認的 localhost 效果納入發布：

- 導覽新增「使用說明」，管理後台移至最右側三條線選單，保留鍵盤、Escape 與點外關閉。
- 繁體中文會員六步／管理員四步，每步有示範截圖，可開大圖；同名範例為陳先生（老師／學生）。
- 首頁 NEWS 與內建指南公告，附右上角使用說明按鈕截圖；既有公告內容／發布時間不改寫。
- 個人賽公開正取與候補姓名、辨識註記及順序，報名後重新讀取，也可手動更新。雙打原有等待搭檔／待確認／正取／候補保留。
- 未刪除且報名中／已截止場次可查看名單；草稿、取消、已結束場次不擴大公開。取消報名不列出。公開資料不含餐食、會員ID、級數或稽核。

## 相容性與更新

版本提高至1.3.0，依賴不變；資料表仍為 `0015_deployment_diagnostics`，沒有migration。
不初始化、匯入或還原球館正式卷，不新增管理員；原帳號、業務、媒體與報名資料保留。
正式更新工具先核對目前已完成的1.2.0球館部署、固定映像、私有ACL與原Compose，再停寫、
以舊runtime成組備份及比對資料，換用新版後先確認資料不變，再接通原Tunnel。
任何未知／部分操作保留原紀錄，禁止盲目重送或改UUID；錯誤不回顯秘密。

發布完成後以本版 Git tag／GitHub Release 的固定來源、registry digest 及更新指令為準，
不覆寫1.2.0標籤，不以latest當球館更新依據。momonong.me其他功能、Worker／Tunnel／
VPC Service、既有Turnstile及Windows設定均不更動。冷開機與球館實際更新結果另行驗收。
